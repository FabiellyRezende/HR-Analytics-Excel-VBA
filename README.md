# HR Analytics — Excel & VBA

Projeto de **HR Analytics desenvolvido em Microsoft Excel e VBA**, utilizando uma base de dados fictícia para demonstrar recursos de automação, análise de dados, pesquisa e filtragem de funcionários e visualização de indicadores.

## 📌 Sobre o projeto

O **HR Analytics** foi desenvolvido como uma solução integrada para gerenciamento e análise de informações de funcionários.

A aplicação possui uma interface principal (**Master**) que permite acessar diferentes funcionalidades do projeto:

- Employee Data
- HR Analysis
- HR Dashboard
- Employee Filter
- Employee Search

O projeto foi desenvolvido utilizando **dados fictícios**, exclusivamente para fins de estudo.

---

## ⚙️ Funcionalidades

### 👥 Employee Data

Base estruturada com informações dos funcionários, incluindo:

- ID
- Nome
- Departamento
- Cargo
- Salário
- Data de admissão
- Status
- Performance
- UF
- CPF

A base utilizada no projeto está disponível no arquivo **`base_rh.xlsx`**.

### 🔎 Employee Search

Ferramenta para pesquisa individual de funcionários.

Permite realizar buscas por:

- ID
- CPF

Os resultados são apresentados diretamente na interface de pesquisa.

### 🔍 Employee Filter

Ferramenta para filtrar a base de funcionários utilizando múltiplos valores de pesquisa.

A funcionalidade permite inserir uma lista de funcionários e aplicar o filtro diretamente na base **EmployeeData**.

**Atalho:** `Ctrl + G`

### 📊 HR Analysis

Área dedicada à análise dos dados dos funcionários e identificação de indicadores relacionados à força de trabalho.

### 📈 HR Dashboard

Dashboard desenvolvido para apresentar os principais indicadores de RH de forma visual e organizada.

Entre os indicadores apresentados estão:

- Total de funcionários
- Funcionários ativos
- Funcionários afastados
- Ex-funcionários
- Salário médio
- Folha salarial
- Performance média
- Tempo médio de empresa
- Distribuição de performance
- Distribuição de tenure
- Funcionários por departamento

### 🏠 Master

Interface principal do projeto, funcionando como central de navegação entre as funcionalidades.

## 🎯 Objetivo

O objetivo deste projeto é aplicar conhecimentos de **Excel, VBA, automação, análise de dados e visualização de informações** no desenvolvimento de uma solução integrada de HR Analytics.

O projeto demonstra a utilização do Excel não apenas como ferramenta de planilhas, mas também como ambiente para desenvolvimento de aplicações automatizadas e interativas.
